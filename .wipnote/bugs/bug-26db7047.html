Phase card shows queued after phase halt (status=failed)

Todo Medium Priority

Part Of:

Description

When a phase halts (gather <<PHASE>> status=failed, e.g. UNCOVERED_MUST_HAVE halt), the application header badge correctly shows failed, but the phase 1 card label reverts to queued with a partially filled progress bar and em-dash duration. Card should reflect the failed/halted state, and could show elapsed time up to the halt from SSE started_at/finished_at if provided.
