Sourcing E2E tests bind :8000 and regenerate tokens — clobbered the production server mid-queue

Todo High Priority

Part Of:

  • trk-cf0dc034

Description

The trk-cf0dc034 yolo's E2E run started a jobsmith server from its worktree cwd on the DEFAULT port 8000, displacing the user's production server (shakestzd repo root) and auto-generating new private/jobsmith.token files in the jobsmith repo + worktree (CWD-relative PRIVATE_TOKEN_PATH). Live apply-queue runs against :8000 got 401s and one in-flight application run was killed. E2E servers MUST bind an ephemeral port (port 0 or a random high port), set JOBSMITH_REPO_ROOT to a scratch repo, and never write tokens outside their scratch dir. Slice-8/e2e conftest needs this hardening.
