Description

The application event log flattens history because transcriptToLogEvent uses now() for phase_boundary, tool_call, tool_result, and text rows even though ApplyRenderer persists payload.ts and the transcript endpoint returns that stored payload. Live phase/specialist/log handlers also stamp rows with receipt time instead of started_at, finished_at, timestamp, or payload.ts. Durable fix: store canonical event_time on LogEvent from payload.ts/log.timestamp/phase timestamps/specialist finished_at, format only at render time, and add tests with historical transcript rows proving replay keeps original times.
