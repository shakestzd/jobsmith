Supervisor and SSE stream stay keyed to the starting slug after canonical slug rekey

Todo High Priority

Part Of:

  • trk-5d3b688f

Description

POST /api/applications registers the supervisor under the URL-derived starting slug. Gather may reconcile to a canonical slug and _cli_apply updates apply_runs.slug, but RunSupervisor has no update_slug path and the events route validates only the requested slug directory. If the EventSource reconnects after the starting directory is renamed, it can 404 or miss the active run; duplicate-run conflict checks can also miss the canonical slug. Durable fix: add a run_id-centered or supervisor.update_slug(old,new,run_id) contract, emit/handle slug_changed in the API path, let events resolve stale-to-canonical slugs, and test reconnect plus duplicate launch across rekey.
