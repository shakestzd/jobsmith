Description

Add a top-level `jobsmith up` Typer command (@app.command on the app at cli.py:42; `api serve` is registered under the api sub-Typer at cli.py:1157-1160 and stays). It reuses the serve path (api/server.py:24 serve → uvicorn.run on the create_app factory) but FIXES the browser-open (per A1): uvicorn.run() at server.py:28 BLOCKS and never returns, so the browser cannot be opened "after" it inline. Instead, start a daemon thread that waits for host:port to accept a connection, then webbrowser.open, and start that thread BEFORE calling uvicorn.run (or use uvicorn Config+Server with a startup callback). Handle PORT_IN_USE: catch the bind error and print a friendly message suggesting --port (exit non-zero), rather than a stacktrace. Flags: --host/--port (default 127.0.0.1:8000), --no-open (skip browser), --bind-public (passthrough; disables auto-auth per slice-3), --dev. --dev EXPLICITLY toggles serving: prod (default) serves bundled static single-port; --dev skips the static mount and targets the developer's separate vite origin (default http://localhost:5173), preserving the two-process hot-reload workflow. Pass the dev flag to create_app via an env var (create_app() currently takes no args — avoid a signature change). If webbrowser.open fails (e.g. headless/Windows quirk), log the URL and continue.
