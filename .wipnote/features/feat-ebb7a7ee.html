Standalone manually-triggered cover-letter step (CLI + API + UI), opt-in by default

Todo Medium Priority

Description

1) jobsmith cover-letter <slug> CLI command generates a cover letter for an EXISTING completed application by re-running the render phase with all non-CL specialists skipped (reuses feat-bd7c2d23 skip_specialists machinery + manifest already-ok skip rule). 2) POST /api/applications/{slug}/cover-letter route + button on the application detail page. 3) Default flips to opt-in: when no flag and no explicit config enable, cover letter is NOT generated during apply runs.
