Description

Add `scripts/build-desktop.sh` orchestrating the full pipeline: npm build (web) -> copy to src/jobsmith/web_dist -> build-sidecar.sh (onefile) -> `tauri build --bundles dmg`. Because the sidecar is ONEFILE, there is no _internal/ to ship — externalBin handles the single binary directly. Configure tauri.conf.json macOS signing: default to ad-hoc (`signingIdentity: "-"`) so the .dmg runs locally without an Apple Developer cert (user approves once in Privacy & Security), and wire the env-driven notarization path: the script reads APPLE_SIGNING_IDENTITY + (APPLE_ID/APPLE_PASSWORD/APPLE_TEAM_ID) and passes them to `tauri build`; if partial/absent it warns and falls back to ad-hoc rather than silently. Document that APPLE_PASSWORD is an app-specific password (appleid.apple.com), not the account password. Optional `.github/workflows` build job.
