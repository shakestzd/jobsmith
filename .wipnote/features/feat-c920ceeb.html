Description

src/jobsmith/apply_local/backends.py defines a Backend protocol — complete_structured(messages, schema, *, temperature) -> (dict|None, parse_ok). Two impls: OpenAICompatBackend wraps the existing OpenAICompatClient (local gemma via vllm-mlx, or Claude's OpenAI-compat endpoint); AnthropicBackend uses the anthropic SDK Messages API with a single STRICT custom tool (input_schema = the node schema, tool_choice forced) and maps the tool_use input back to a dict. Both SHARE the llm_rescore robust-parse helpers (extract them to a shared util — do not duplicate). resolve_backend(config, node_name) returns the per-node backend (node_backends override, else node_backend default).
