Description

New 'Postings' section in the jobsmith web UI: ranked list (llm_score desc, then fast_score desc, then first_seen desc as stable tie-breaker) showing title/company/source/triage-score/rationale/age, filters (source, specialty, min score, status), actions: dismiss, queue, and 'start application' — POST /api/postings/{id}/promote calls the EXISTING application-creation path (create_application, applications.py:552-582, ApplicationCreate{url, jd_text}) with the posting's url + cached jd_text; for email-sourced snippet-only postings the JD is fetched at promote via the existing fetcher — IF that fetch fails the promote still succeeds with jd_text empty and the response carries a jd_fetch_failed warning the UI surfaces (the apply pipeline's own JD handling takes over; promote is never blocked on a fetch). Wires the new view into the nav: ViewName union (web/src/types.ts:95-105) + sidebar (web/src/app/chrome.tsx) + route switch. API: GET /api/postings (filtered), POST /api/postings/{id}/status, POST /api/postings/{id}/promote. Inbox badge shows new-since-last-visit count.
