Description

A funnel view in the web UI fed by a new GET /api/funnel: stage counts (sourced -> queued -> promoted/applied -> interview -> offer / rejected) with conversion rates between adjacent stages, a per-source breakdown (which boards/ email senders produce postings that become applications and interviews), and a time-window filter (7/30/90 days/all; cohort = posting first_seen in window). Applications gain interview/offer in the UI status picker (vocabulary added in slice-1) so outcomes are recorded from the application detail — closing the loop the BECU rejection exercised manually via SQL. Funnel uses the APPLICATION's fit score post-promotion (triage score is pre-funnel ranking only). Nav wiring: ViewName (types.ts) + chrome.tsx sidebar, same as slice-5.
