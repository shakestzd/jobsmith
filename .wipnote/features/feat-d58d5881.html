Description

Make `pip install` / `uv tool install` ship the UI so the end user never runs npm. Add a custom hatchling build hook (new hatch_build.py + a NEW [tool.hatch.build.hooks.custom] section in pyproject.toml — this is separate from, not an extension of, the existing [tool.hatch.build.targets.wheel.force-include] at pyproject.toml:100-101 which already maps templates→jobsmith/templates). At wheel-build time the hook runs `vite build` in web/ FRESH (never trusting a stale on-disk web/dist) and copies the output into the package tree at src/jobsmith/web_dist/, then force-includes it in the wheel (add a second force-include entry alongside templates). The slice-1 locator prefers this bundled path. Gitignore BOTH web/dist and src/jobsmith/web_dist (build artifacts, currently neither is ignored). Make the hook a no-op with a clear message if npm/node is unavailable. Add a visibility check so a UI-less wheel is detectable: `jobsmith doctor` (and/or `jobsmith --version`) reports "UI bundled: yes/no".
