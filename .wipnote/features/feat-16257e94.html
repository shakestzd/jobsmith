Refactor client.ts so a single MUTABLE runtime token (read from window.__JOBSMITH__, VITE var as fallback) feeds BOTH the Authorization header path AND buildEventsUrl's query-param. Inject ONLY on a localhost bind (detect 127.0.0.1/::1 from the bind/ request); on --bind-public, do NOT inject and require explicit auth. Add a restrictive CSP on the served index and ensure the token is excluded from the SSE event-log redaction view.
