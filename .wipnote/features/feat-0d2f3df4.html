Description

src/jobsmith/llm/vllm_mlx.py manages the local engine — start() launches `vllm-mlx serve <model> --host 127.0.0.1 --port <free> --enable-auto-tool-choice --tool-call-parser gemma4 --reasoning-parser gemma4` (NO --continuous-batching — it crashes gemma-4), with a free-port pick + conflict pre-check and an idempotent PID-lock; health() polls /v1/models and classifies loading (~20-30s cold) vs crashed vs ready; stop() terminates with no orphan. deps.py detects whether vllm-mlx is installed and surfaces a guided `uv pip install vllm-mlx` hint. The spike doc is the authoritative flag source (upstream README defaults to batching).
