Description

In main.rs: on setup, generate a random token, spawn the sidecar via `app.shell().sidecar()` with env `JOBSMITH_API_TOKEN=` (stdin kept open so the stdin-EOF sentinel works), read `JOBSMITH_LISTENING_PORT=` from the child stdout (rx channel), tee stdout/stderr to a log file at `~/Library/Logs/Jobsmith/sidecar.log`, poll `GET /health` until 200 (with a timeout), then navigate the main WebviewWindow to `http://127.0.0.1:/`. Jobsmith's existing localhost shim (staticui.py:208-216) reads the same token from auth.py and injects `window.__JOBSMITH__={token,apiBase}` before the React app boots — inject-before-load auth with zero new UI code. Lifecycle: on macOS, bind `WindowEvent::CloseRequested` to fully quit the app (kill the child + process::exit) so closing the window is an explicit quit (no orphaned sidecar, no headless dock icon). If `/health` never returns 200 within the timeout, show a native error dialog (Retry + "open log") rather than a blank window.
