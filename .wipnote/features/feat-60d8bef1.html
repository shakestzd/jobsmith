Description

Add a one-time/idempotent backfill (e.g. CLI: jobsmith reuse backfill [--all]) that populates the reuse tables (canonical_requirements, requirement_evidence_map, application_fingerprints, and the company-research cache) from existing applications under the applications dir. Today the store only self-populates on new apply runs via _persist_reuse_tables in _cli_apply.py, so the existing app corpus is invisible to the planner and reuse cannot fire against prior work. Mirror the existing persist/fingerprint/evidence-map logic. Idempotent; safe to re-run. Prereq: migration 009 applied.
