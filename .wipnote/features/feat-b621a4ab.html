Description

Add a NEW desktop sidecar entry point `src/jobsmith/desktop/sidecar_main.py` that: (a) pops JOBSMITH_PUBLIC_BIND from env so the loopback auth shim always fires; (b) resolves the data dir via the existing platformdirs dependency and exports PLAYWRIGHT_BROWSERS_PATH BEFORE any Playwright import; (c) selects a free ephemeral port (binds 127.0.0.1:0, retries on failure) and prints `JOBSMITH_LISTENING_PORT=<n>` to stdout so Rust learns the port without a cross-process race; (d) starts uvicorn on that port via the existing `jobsmith.api.main:create_app` factory (no browser auto-open); (e) installs a stdin-EOF shutdown sentinel (daemon thread on sys.stdin.read(); on EOF os._exit(0)) plus a SIGTERM handler. Author a PyInstaller spec `packaging/jobsmith-sidecar.spec` (ONEFILE / -F) collecting uvicorn/fastapi/playwright/claude-agent-sdk hidden imports and bundling the pre-built `src/jobsmith/web_dist/` as data. `scripts/build-sidecar.sh` REQUIRES web_dist to be pre-populated (it does NOT run npm — build-desktop.sh owns that) and emits the binary named with the host target triple into `src-tauri/binaries/`. cli.py is NOT touched.
