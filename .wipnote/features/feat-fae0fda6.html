Approach A propose/apply for the cover letter. Chat agent emits a fenced jobsmith-proposal JSON block (no FS access); SSE surfaces it as a proposal event; UI shows an old/new diff card with Apply/Reject; Apply runs check_draft fact-check gate, then writes cover-letter-draft.md and re-renders. Gate failure rejects the apply and returns reasons to chat. Establishes the shared propose/apply mechanism for later assets (work.yml, bullets, resume).
