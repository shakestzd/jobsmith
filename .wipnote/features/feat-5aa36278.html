Description

Let the user manually edit resume section YAMLs and the cover letter, routing both through the same propose->review(diff)->apply->re-render panel the chat uses. Reuses receiveProposal() injection + existing /resume/apply and /cover-letter/apply endpoints. Resume: section editor builds a ChatProposal(asset=resume,target_file) and calls receiveProposal. Cover letter: reroute existing inline Save through receiveProposal(asset=cover_letter) so manual edits also get the diff + failedClaims review instead of a silent direct PUT.
