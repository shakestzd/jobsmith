Description

Frontend onboarding wizard in the existing web app: first-run flow to upload a resume / LinkedIn export, paste text, or give a URL; kicks off onboarding via the slice-3 API path (in-process asyncio.to_thread + supervisor.register_run, NOT a detached CLI subprocess); streams progress over the existing SSE channel (supervisor.py); renders the gap-interview questions; lands on "masters ready". New API endpoints wrap the slice-3..5 pipeline: POST /onboard (multipart inputs, reusing slice-3's validator — not a duplicate), GET onboarding status, answer gap questions. Enforce a multipart size cap (e.g. 10MB, 413 on oversize).
