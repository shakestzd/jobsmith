Description

Surface an "offline mode" option in the desktop app that routes CHAT and SCORING to a local OpenAI-compatible server instead of the cloud. Extend `src/jobsmith/desktop/deps.py` to detect a running local server (MLX mlx_lm.server at 127.0.0.1:8080/v1 or Ollama at 127.0.0.1:11434/v1) and whether the runtime is installed. Add desktop-gated routes to `src/jobsmith/api/routes/desktop.py`: `GET /api/desktop/llm/status` (detected servers + installed runtimes) and `POST /api/desktop/llm/offline-mode` (enable -> writes the pluggable-backend `llm` config from plan-938f735b: provider=openai_compatible + the detected base_url/model). If the runtime is installed but not running, offer to launch it (mlx_lm.server / `ollama serve`) as a managed child; if absent, show guided install. A React `OfflineModeToggle` component drives this. Apply pipeline still uses `claude` (slice 6) — offline mode covers chat + scoring only (the agentic apply pipeline is out of scope here).
